# Six-project hero

The top hero now covers the six projects currently curated in the profile. All models are original code-defined geometry. The products remain independent; no connections run between products. Individual project banners and the README body retain their existing content.

| Type | Project | Model and verified workflow |
|---|---|---|
| Repository intelligence | CodeForge AI | Real source-length repository layers, source chunks, lexical/vector retrieval, rank fusion and commit/file/line citations; backend/scanner.py, backend/rag.py and backend/main.py. |
| Document intelligence | Vericore | Curved PDF/TXT pages, page/section-aware passages, ChromaDB, evidence gate, answer or NOT_FOUND; backend/app/services/retriever.py and backend/app/api/chat.py. |
| Developer tooling | Intervexa | Directed Python import relationships, declarations and advisory selected-PR comparison paths; backend/app/intelligence.py and backend/app/analyzer.py. |
| Video-analysis services | Nexvio | Video input, schematic posture landmarks, queued processing and task-status results; interview-analysis-service/api/routes.py, task_queue.py and posture-analysis-service/core/pose_detector.py. No landmark positions or outputs represent a real analyzed video. |
| Full-stack AI chat | EchoVault AI | User/assistant message bubbles, /api/chat and browser-local history; src/App.jsx and api/chat.js. No fabricated message content is shown. |
| Resume intelligence | Smart Resume AI | PDF/DOCX input and structured skills, role suggestions and feedback; app.py and resume_parser.py. No ATS accuracy, hiring outcomes or scores are asserted. |

Source shapes and strokes are explanatory symbols, not recorded query results, messages, documents or measured execution. The source-count data and original three workflows were inspected earlier in this redesign; the additional workflow code was checked against the new hero models.

The renderer exports a static 1800 × 1320 PNG. GitHub runs no JavaScript from the README. The hero source can be regenerated using the repository's tools/portfolio-3d/render.py script.
