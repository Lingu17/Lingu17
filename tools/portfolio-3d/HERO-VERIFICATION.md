# Engineering hero

The hero is a conceptual software workbench, designed around the profile owner’s AI and full-stack engineering roles. It does not showcase individual projects.

Original Three.js geometry depicts overlapping code windows, a connected-node panel, a syntax tile, document layers and a three-tier software foundation. These are broad engineering symbols, not a product screenshot, actual system topology or measured result. Source strokes are schematic, and the backdrop routes are decorative.

`hero.html` supplies editable typography and layout. `profession-models.js` supplies geometry, materials, lighting and camera. The exported 1800 × 620 PNG is static and works in GitHub Markdown. Individual project banners and the README body are preserved.
